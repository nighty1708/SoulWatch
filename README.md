# SoulWatch

SoulWatch is a World of Warcraft Vanilla (1.12) addon that helps Warlocks manage Soulstones during raids.

It provides synchronized assignments, individual cooldown timers and a simple interface to keep Soulstone management organized across the raid.

---

## Features

- Assign Soulstones to raid members
- Synchronize assignments between all Warlocks using the addon
- Individual 30-minute cooldown timer for each Warlock
- Automatic Soulstone detection
- Cast Soulstones directly from the addon
- Lightweight and easy-to-use interface

---

## Installation

1. Download the latest release.
2. Extract the `SoulWatch` folder.
3. Copy it into:

```
World of Warcraft
└── Interface
    └── AddOns
        └── SoulWatch
```

4. Restart the game.
